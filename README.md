
# visionTag

### Computer Vision Based Smart Image Annotation System

visionTag is an AI-powered image annotation system
that automatically detects objects in images using
YOLOv8 and generates bounding-box annotations.

## Features

- Automatic object detection
- Bounding box generation
- Object class identification
- Confidence threshold control
- YOLO-format annotation export
- Annotated image download
- Interactive Streamlit interface

## Technologies Used

- Python
- YOLOv8
- Ultralytics
- Streamlit
- Pillow
- Google Colab

## Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/visionTag.git

Move into the project folder:

cd visionTag

Install dependencies:

pip install -r requirements.txt

## Run the Application

streamlit run app.py
